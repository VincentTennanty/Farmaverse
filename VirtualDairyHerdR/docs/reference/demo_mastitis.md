# Demo Mastitis Dataset

A synthetic dairy herd of 200 cows with mastitis labels applied at 15%
prevalence. Built on top of
[demo_herd](https://vincenttennanty.github.io/Farmaverse/VirtualDairyHerdR/reference/demo_herd.md)
with mastitis disease effects applied. Suitable for binary
classification exercises.

## Usage

``` r
demo_mastitis
```

## Format

A tibble with 200 rows and 14 columns. All columns from
[demo_herd](https://vincenttennanty.github.io/Farmaverse/VirtualDairyHerdR/reference/demo_herd.md)
plus:

- temperature:

  Numeric. Body temperature in °C. Elevated in mastitis cases.

- rumination_minutes:

  Integer. Daily rumination time in minutes. Reduced in mastitis cases.

- mastitis:

  Logical. TRUE if the cow has mastitis. The classification target.

## Source

Generated by VirtualDairyHerdR. See `data-raw/generate_demo_data.R`.

## Details

Mastitis cases (approx. 15% of cows) have:

- Milk yield reduced by 15–40%

- SCC elevated 5–20x

- Body temperature increased +0.5 to +2.5 °C

- Rumination reduced by 20–50%

Generated with:

    demo_mastitis <- simulate_mastitis(demo_herd, prevalence = 0.15, seed = 42)
