# Demo Dairy Herd Dataset

A synthetic dairy herd of 200 cows with milk production data, generated
using the full VirtualDairyHerdR simulation pipeline. Suitable for
general exploration, visualisation, and regression exercises.

## Usage

``` r
demo_herd
```

## Format

A tibble with 200 rows and 11 columns:

- cow_id:

  Character. Unique cow identifier (e.g. "COW0001").

- breed:

  Character. Breed — Holstein, Friesian, Jersey, or Crossbred.

- age:

  Integer. Age in years.

- lactation:

  Integer. Lactation number (parity), 1–6.

- days_in_milk:

  Integer. Days in milk at snapshot date, 1–305.

- milk_kg:

  Numeric. Daily milk yield in kg.

- fat_percent:

  Numeric. Milk fat percentage.

- protein_percent:

  Numeric. Milk protein percentage.

- scc:

  Integer. Somatic cell count (cells/mL).

- synthetic_data:

  Logical. Always TRUE — flags this as synthetic data.

- source:

  Character. Always "VirtualDairyHerdR".

## Source

Generated by VirtualDairyHerdR. See `data-raw/generate_demo_data.R`.

## Details

Generated with:

    farm      <- simulate_farm(name = "Greenfield Farm", n_cows = 200, seed = 42)
    herd      <- simulate_herd(farm = farm)
    demo_herd <- simulate_milk(herd, seed = 42)
